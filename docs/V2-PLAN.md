# Global Copilot V2

Confirmed direction: mobile-first speaking coach for overseas life, social connection and business. Keep warm white/gray/emerald; desktop two-column working surface. Four tabs: Practice, Scenarios, Review, Growth. Keep Meeting Prep, Quick English and professional library as secondary tools.

Primary journey: choose real goal → scaffold (optional) → dialogue → contextual help → retry → evidence-based debrief → active review → delayed transfer challenge. Free conversation avoids unsolicited corrections; simulation stays in character; coach help is separate.

Stages: basic needs, everyday transactions, social follow-up, problem resolution, work communication, complex negotiation. Life/social/business tracks are independent. A course finished is not an ability mastered. Advancement requires independent evidence in two contexts and a delayed retest. Skipping assessment leaves ability unassessed.

P0: navigation and responsive practice surface.
P1: normalized session/review/evidence records, account separation, optional private self-host Codex adapter and recovery.
P2: turn-taking voice, editable transcript, playback/speed/subtitles, interruption, text fallback, autosave.
P3: guided/free/simulation modes, context help, adaptive vocabulary and short turns.
P4: listen/recognize/say/transfer review with due scheduling and source links.
P5: initial challenge, evidence-gated stages, next exercise recommendations.
P6: 36 scenes, content library, legacy meeting tools, migration, automated integration/security checks and deployment.

Release gates: actual model authorization and mobile microphone checks need the user's account/device; do not label these verified from mocks. Self-host deployment needs a reachable server and TLS domain.
